# 美术生成记录

本项目全部正式视觉素材由内置 `image_gen__imagegen` 生成，不含《Save the Date》原作图片、脚本或素材。图片仅作 WebP 编码压缩，未用 SVG、emoji 或程序绘画替代；透明立绘保留 alpha。

## 风格

原创都市雨夜、成熟图像小说气质；水彩与不透明水粉、铅笔边缘、纸张颗粒；低饱和墨青阴影和暖金灯光。所有素材均避免可读文字，标题和剧情由 HTML 文字层保证中文清晰。
